# 🔥 Flame & Fork

A modern and responsive restaurant website designed to provide an attractive, user-friendly, and engaging online dining experience.

##  Live Demo

[Visit Flame & Fork](https://preview--flame-fork-delights.lovable.app/?__lovable_sha=2962cd02)

##  About The Project

Flame & Fork is a restaurant website created as a frontend web development project.

The website focuses on a clean and modern interface where visitors can explore the restaurant, view featured dishes, browse the menu, and discover the overall dining experience.

The project was designed with a strong focus on visual presentation, responsive layouts, and user-friendly navigation.

##  Features

- 🏠 Modern homepage
- 🍽️ Restaurant menu section
- 📱 Responsive design for different screen sizes
- 🧭 Easy and intuitive navigation
- 🔥 Restaurant branding and visual identity
- 📸 Food and restaurant imagery
- 📞 Call-to-action sections
- 🎨 Clean and engaging user interface

##  Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite

##  Responsive Design

The website is designed to provide a smooth browsing experience across:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

##  Project Goal

The goal of this project was to practice frontend web development while creating a realistic restaurant website with a professional and visually appealing user interface.
